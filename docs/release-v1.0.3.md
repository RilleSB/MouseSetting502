# MouseSetting502 v1.0.3

Обновление стабильности профилей, макросов и управления DPI для Windows.

- Сохранение настроек через атомарную замену файлов; откат изменений профилей и макросов при ошибке записи.
- Остановка макросов дожидается завершения потока и отпускает удерживаемые клавиши и кнопки. Устаревшие события перехватчиков больше не запускают макросы после смены профиля.
- Переименование и удаление макросов обновляет назначения во всех профилях.
- Запросы DPI учитывают профиль и порядок команд. Интерфейс показывает подтверждённое мышью значение и отдельно сообщает об ошибке сохранения.
- Закрытие окна скрывает приложение в рабочий трей; если создать трей не удалось, приложение завершается. Выход дожидается завершения начатой операции с устройством.
- Проверка обновлений получает последний релиз GitHub и SHA-256 официального `.exe`. Исправлено ложное сообщение о совпадении хэша; сетевые запросы ограничены по времени.
- Добавлена команда `--check-updates` для проверки версии и хэша без запуска интерфейса и обращения к мыши.

Скачайте **MouseSettings502.exe**, завершите предыдущую версию через меню значка в трее и замените файл приложения. Пользовательские настройки хранятся отдельно в `%APPDATA%\ghub_rust`.

Проверка обновлений открывает страницу релиза для скачивания; автоматическая замена запущенного файла не выполняется.

Проверки: форматирование, Clippy без предупреждений, автоматические тесты, release-сборка. Предыдущая локальная проверка этих исправлений на G502 HERO подтвердила изменение DPI, переключение профилей, восстановление после перезапуска и скрытие окна в трей. Физические кнопки G6–G9, Esc во время макроса, переподключение USB и пункт выхода в системном меню требуют отдельной ручной проверки.
