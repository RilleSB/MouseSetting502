# MouseSetting502 V2.0.0

Новый интерфейс и переработанные макросы для проводной Logitech G502 HERO.

- Новый тёмный интерфейс: главная, назначения кнопок с двумя ракурсами, подсветка, DPI и профили. Собственный значок и SVG-иллюстрации вместо логотипа Logitech и изображения мыши.
- «Сообщество» показывает до пяти последних релизов GitHub с версиями, датами и заметками; есть обновление сводки и ссылки на полные релизы. Вкладка «Игры» удалена.
- Четыре режима макросов: однократный, при удержании, переключатель и последовательность с фазами нажатия, удержания и отпускания. Редактор шагов, запись клавиатуры и мыши, изменение пауз и стандартной задержки.
- Сохранена совместимость со старыми JSON-макросами. Отмена освобождает удерживаемый ввод; удалён искусственный минимум цикла 10 мс. Заданные миллисекунды не являются гарантией точности реального времени Windows.
- Исправлен выбор эффекта подсветки в интерфейсе. Аппаратные эффекты определяются по списку конкретной зоны; исправлены период и яркость «Дыхания» и цикла. Ползунки применяются к мыши, синхронизация сохраняет выбранный эффект, выключение обрабатывает обе зоны через CLI.
- Автозагрузка учитывает отключение записи в Windows и распознаёт другую копию MouseSettings502.exe. Статус можно обновить в настройках; отключённая Windows запись не выдаётся за работающую автозагрузку.
- SHA-256 EXE вычисляется в фоне, чтобы не задерживать появление окна.

## Установка

Скачайте **MouseSettings502.exe**. Завершите предыдущую версию через меню значка
в трее и замените EXE. Настройки и макросы хранятся отдельно в `%APPDATA%\ghub_rust`.
Если путь к файлу изменился, обновите запись автозагрузки в настройках приложения.
Если Windows отключила запись, включите её в «Диспетчер задач → Автозагрузка приложений».

Поддерживается проводная **G502 HERO (046D:C08B)**. Для программных назначений
и подсветки отключите режим внутренней памяти. Запись макросов работает внутри
редактора, а не глобально во всех приложениях. Подробности: `docs/macros.md`.

Проверено: автоматические тесты, форматирование, Clippy и release-сборка.
На подключённой G502 HERO подтверждены ответы на команды цикла, дыхания и
выключения. Состояние автозагрузки проверено в Windows; повторный вход в систему
в рамках проверки не выполнялся.
